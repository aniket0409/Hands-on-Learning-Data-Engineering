What does a data engineer do?



=> Data engineers maintain, develop, implement processes that take raw data and provide high quality consistent information to downstream users e.g. Data analysts, Data Scientists etc.



How is this different from a data analyst?

=> Data analysts work on refined data to discover pattern in the historical data where as data engineers work on raw data collected from various sources to generate the refined data that the data analysts work on.



What part of this role feels new to me?
